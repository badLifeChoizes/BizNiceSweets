<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| env → config | JWT secret and admin password enter via environment; must stay SecretStr, never logged |
| DB ← service | Hashed credentials and token hashes are written; plaintext must never reach the DB |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-02-01 | Information Disclosure | config.py JWT secret / admin password | mitigate | Type both as `SecretStr`; read only via `.get_secret_value()`; never log/repr (matches postgres_password) |
| T-02-02 | Spoofing/Elevation | JWT decode | mitigate | `decode_access_token` always passes `algorithms=["HS256"]` as a list (prevents alg-confusion CVE class) |
| T-02-03 | Information Disclosure | password storage | mitigate | Argon2id via `pwdlib`; no bcrypt 72-byte truncation; plaintext never persisted |
| T-02-04 | Information Disclosure | refresh token storage | mitigate | Store SHA-256 of token (`token_hash` String(64)), never the raw token |
| T-02-05 | Tampering | dependency supply chain | mitigate | Pin `pyjwt==2.13.0` + `pwdlib[argon2]==0.3.0`; explicitly exclude python-jose (4 CVEs) and passlib (abandoned) |
</threat_model>
