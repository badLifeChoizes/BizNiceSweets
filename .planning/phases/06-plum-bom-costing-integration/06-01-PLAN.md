## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| migration → live schema | DDL applied to production database; incorrect FK/cascade could corrupt referential integrity |
| schema layer → API input | Pydantic schemas are the first validation gate for untrusted BOM/AVL/cost payloads |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-06-01 | Tampering | plum_part_revision.selected_vendor_link_id FK | mitigate | FK ondelete=SET NULL prevents dangling reference when an AVL link is removed (Zone 3 of migration 0006) |
| T-06-02 | Tampering | plum_avl_price_break orphan rows | mitigate | FK ondelete=CASCADE removes price breaks when parent AVL link is deleted; no orphan cost rows |
| T-06-03 | Tampering | duplicate BOM/AVL rows | mitigate | UniqueConstraint(parent_revision_id, child_part_id) and UniqueConstraint(part_id, vendor_id) enforced at DB level |
| T-06-04 | Information Disclosure | cost values as float precision leak | accept | Numeric(12,4) (not float) used for all cost columns — exact fixed-point; no rounding-error disclosure |
| T-06-SC | Tampering | pip install openpyxl | mitigate | openpyxl [OK] in RESEARCH Package Legitimacy Audit (PyPI, ~15yr, slopcheck OK) — no human gate required |
</threat_model>
