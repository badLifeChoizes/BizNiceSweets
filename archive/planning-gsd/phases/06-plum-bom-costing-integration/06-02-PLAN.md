## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-06-05 | Tampering | add_bom_line on Released revision | mitigate | service raises 422 when revision.status != "draft" (D-01 immutability) |
| T-06-06 | Tampering | BOM cycle insertion | mitigate | _would_create_cycle ancestor BFS before insert; 422 on cycle; visited-set guard at read time |
| T-06-07 | Tampering | AVL link to non-vendor / wrong partner | mitigate | add_avl_link validates syerp_partner.is_vendor=true; 422 if absent |
| T-06-08 | Elevation of Privilege | unauthorized BOM/AVL/cost mutation | mitigate | require_permission("plum:write") on every mutating endpoint; require_permission("plum:read") on reads |
| T-06-09 | Repudiation | untracked cost/BOM/AVL changes | mitigate | write_audit on every mutation (bom.*, avl.*, part.cost_updated) — medical-device traceability posture |
| T-06-10 | Information Disclosure | float cost precision drift | accept | Decimal + Numeric(18,6) throughout; no float in cost arithmetic |
