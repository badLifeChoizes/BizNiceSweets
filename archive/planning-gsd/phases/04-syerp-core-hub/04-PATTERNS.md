**`lazy="selectin"` on relationships** (lines 77–80) — mandatory for async context:

**Module docstring convention** — open with a triple-quoted docstring describing what tables are defined, then the Phase comment noting what phase added them (mirrors lines 1–14 of auth/models.py).

**CRITICAL:** `syerp_partner` uses `active: Mapped[bool]` (not `is_active`) to distinguish from auth's `User.is_active`; `syerp_gl_account` uses `account_type` (not `type` — `type` shadows Python built-in and is a SQLAlchemy reserved word).

### Permission Gating
**Source:** `backend/app/modules/auth/dependencies.py` lines 97–127
**Apply to:** All new SYERP router endpoints
```python
def require_permission(permission_code: str):
    async def _check(current_user=Depends(get_current_user)):
        for role in current_user.roles:
            if role.name == "admin":
                return current_user
            for perm in role.permissions:
                if perm.code == permission_code:
                    return current_user
        raise HTTPException(
            status_code=status.HTTP_403_FORBIDDEN,
            detail=f"Permission denied: {permission_code} required",
        )
    return _check
```
Usage: `Depends(require_permission("syerp:read"))` on GET endpoints; `Depends(require_permission("syerp:write"))` on POST/PATCH.
