## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| browser UI → API | All shell mutations (settings save, module toggle, logout) cross to the gated /api/v1/core endpoints |
| UI gating (admin menu, disabled Switch) | Convenience layer only — not a security boundary; the backend gates are authoritative |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-03-10 | Elevation of Privilege | admin-only menu items (Settings/Modules/Users) | mitigate | UI conditionally renders these only for the `admin` role, but this is convenience; a non-admin who navigates directly still hits the backend 403 from 03-02 (settings/modules PATCH remain admin-only).
