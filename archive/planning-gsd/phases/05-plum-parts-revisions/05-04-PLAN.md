## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| user-rendered revision data → DOM | description / notes / reason rendered in the timeline; untrusted string content |
| frontend FSM strip gating → API | The advance-status strip only shows valid transitions; the API (05-02) is the real FSM + immutability boundary |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-05-12 | Tampering | XSS via revision description/notes/reason rendered in the timeline | mitigate | React auto-escapes JSX interpolation; no `dangerouslySetInnerHTML` in PartDetail or the dialogs |
| T-05-13 | Tampering | Frontend allowing an illegal transition | accept | The strip only offers valid transitions, but the API VALID_TRANSITIONS guard (05-02, T-05-07) is the authoritative defense; a crafted request still returns 422 |
| T-05-14 | Tampering | Release without confirmation auto-obsoleting prior released | mitigate | AdvanceStatusDialog forces explicit confirmation before the irreversible release (D-08); the supersede + audit happen server-side (05-02) |
| T-05-SC | Tampering | npm installs | accept | No new packages — Card and all components already installed (UI-SPEC: "No new shadcn installs required") |
</threat_model>
